# DMM Markdown Paste

DMMオンラインサロンの管理画面で、Markdown原稿をSummernote編集欄へ貼り付けるだけでDMM向けのリッチテキストへ変換するChrome拡張です。

## 使い方

1. ChatGPT、Notion、エディタなどで完成したMarkdown原稿をコピーします。
2. DMMオンラインサロン管理画面の「公開部分」または「限定部分」の編集欄をクリックします。
3. `Cmd+V` / `Ctrl+V` で貼り付けます。
4. Markdown記法が含まれている場合、自動でリッチテキストへ変換します。

### 重要: Markdown貼り付けは全文置換です

Markdownとして認識された内容を貼り付けると、フォーカスしているDMM編集欄の既存内容を削除し、変換後のMarkdown原稿で全文を置き換えます。

既存内容がある場合は、置き換え前に確認ダイアログを表示します。

この仕様により、既存の太字・リンク・箇条書き・見出しなどの内部へブロック要素が挿入されてHTML構造が崩れる問題を避けています。

通常のプレーンテキストを貼り付けた場合は、拡張機能は介入せず通常の貼り付けとして処理されます。

## 対応記法

| Markdown | DMM上の表示 |
|---|---|
| `# 見出し` / `## 見出し` | 大見出し |
| `### 見出し` | 小見出し |
| `**太字**` | 太字 |
| `[文字](https://...)` | リンク |
| `![alt](https://...)` | 画像 |
| `[image](https://...)` | 画像 |
| `- 項目` | 箇条書き |
| `1. 項目` | 番号付きリスト |
| `> 引用` | 引用 |
| `---` | 区切り線 |

## インストール（開発版）

1. このリポジトリをダウンロードします。
2. Chromeで `chrome://extensions/` を開きます。
3. 「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」を選びます。
5. `manifest.json` が入っているフォルダを指定します。
6. DMMオンラインサロン管理画面を再読み込みします。

## 権限とプライバシー

この拡張機能は、`https://owner.lounge.dmm.com/*` の編集画面上でのみ動作します。

- 外部サーバーへのデータ送信なし
- 閲覧履歴の収集なし
- 入力内容の保存なし
- アカウント情報の収集なし
- 広告・解析SDKなし

貼り付けたMarkdownはブラウザ内でHTMLへ変換され、フォーカス中のDMM編集欄へ反映されます。

## 注意事項

Markdown貼り付け時は編集欄の全文を置換します。既存原稿へ部分的にMarkdownを挿入する用途には対応していません。

DMMオンラインサロン管理画面のDOM構造やSummernote実装が変更された場合、動作しなくなる可能性があります。

DMM.comとは無関係の非公式ツールです。
