# DMM Markdown Paste

DMMオンラインサロンの管理画面で、MarkdownをSummernote編集欄へ貼り付けるだけでDMM向けのリッチテキストへ変換するChrome拡張です。

## 使い方

1. ChatGPT、Notion、エディタなどでMarkdownをコピーします。
2. DMMオンラインサロン管理画面の「公開部分」または「限定部分」の編集欄へ移動します。
3. `Cmd+V` / `Ctrl+V` で貼り付けます。
4. Markdown記法が含まれている場合だけ、自動でリッチテキストへ変換されます。

通常の文章を貼り付けた場合は、通常の貼り付けとして処理されます。

## 対応記法

| Markdown | DMM上の表示 |
|---|---|
| `# 見出し` / `## 見出し` | 大見出し |
| `### 見出し` | 小見出し |
| `**太字**` | 太字 |
| `[文字](https://...)` | リンク |
| `![alt](https://...)` | 画像 |
| `[image](https://...)` | 画像 |
| `- 項目` | 箇条書き |
| `1. 項目` | 番号付きリスト |
| `> 引用` | 引用 |
| `---` | 区切り線 |

## インストール（開発版）

1. このリポジトリをダウンロードします。
2. Chromeで `chrome://extensions/` を開きます。
3. 「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」を選びます。
5. `manifest.json` が入っているフォルダを指定します。
6. DMMオンラインサロン管理画面を再読み込みします。

## 権限とプライバシー

この拡張機能は、`https://owner.lounge.dmm.com/*` の編集画面上でのみ動作します。

- 外部サーバーへのデータ送信なし
- 閲覧履歴の収集なし
- 入力内容の保存なし
- アカウント情報の収集なし
- 広告・解析SDKなし

貼り付けたMarkdownは、ブラウザ内でHTMLへ変換され、そのまま現在のDMM編集欄へ挿入されます。

## 注意事項

DMMオンラインサロン管理画面のDOM構造やSummernote実装が変更された場合、動作しなくなる可能性があります。

DMM.comとは無関係の非公式ツールです。
